# Ulcer Patient Dashboard Analysis

## Project Overview

This project presents an interactive Power BI dashboard analyzing ulcer patient data. The dashboard explores patient demographics, clinical characteristics, treatment patterns, and health outcomes to support data-driven decision-making in healthcare settings.

## Dashboard Pages

### 1. Overview & Demographics

* Total Patients
* Gender Distribution
* Age Group Distribution
* Hospitalization Rate

### 2. History & Symptoms

* Ulcer History Distribution
* Pain Pattern Distribution
* Smoking Status
* Alcohol Intake

### 3. Clinical & Treatment

* Ulcer Depth Levels
* Medication Distribution
* H. pylori Status
* Average Ulcer Size

### 4. Outcomes

* Ulcer Outcome Distribution
* Outcome by Age Group
* Outcome by Treatment

## Tools Used

* Power BI
* Python (Pandas, Matplotlib)
* GitHub

## Key Insights

* Patient demographics show balanced gender distribution.
* Clinical severity varies across ulcer depth levels.
* Treatment outcomes differ across patient groups.
